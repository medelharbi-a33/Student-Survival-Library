# Contributing

Thank you for helping other students. Every link you add can change someone's future.

## What to add
- New scholarships, courses, tools, programmes or templates
- Fixes for broken or outdated links
- Translations into other languages
- Country-specific guides (visa, housing, banking, student life)

## Rules for resources
1. **Official or well-established sources only.** Prefer the organisation's own site.
2. **No scams or paywalled "free" offers.** If there are conditions, tag it 🎁.
3. Use the cost tags: 🆓 free · 🎁 free with conditions · 💲 paid but worth knowing.
4. Add a **one-line description** of what the resource offers.
5. Do not add affiliate links.
6. Do not add pirated material.

## How to contribute
1. Fork the repository.
2. Edit the right file in `docs/` (or add one in `templates/`).
3. Open a pull request using the template.
4. Or open a **New resource** issue if you do not want to edit files.

## Style
- Plain English; short sentences.
- Keep tables tidy.
- One resource per bullet.

## Reporting problems
Broken links, wrong deadlines or suspicious resources? Open an issue with the page and the problem.

## Code of conduct
Be kind and respectful. No harassment, discrimination or spam.
